# Data_Analyst_Project
This project is an interactive Mobile Sales Dashboard built using Microsoft Power BI.It provides a comprehensive analysis of mobile phone sales across different cities, brands, models, and payment methods.The dashboard helps stakeholders quickly understand sales performance, customer behavior, and key business trends.

**🎯 Key Features**
**📈 Sales Overview**
      -Total Sales: 769M
      -Total Quantity Sold: 19K
      -Total Transactions: 4K
      -Average Sales Value: 40K
**🌍 Geographical Insights**
      -Interactive map showing Total Sales by City
**📅 Time-Based Analysis**
      -Monthly sales trends
      -Daily sales performance
**📱 Product Insights**
      -Sales breakdown by Mobile Model
      -Brand-wise performance comparison
**💳 Payment Analysis**
      -Transactions by Payment Method (UPI, Debit Card, Credit Card, Cash)
**⭐ Customer Insights**
      -Customer ratings distribution
**🎛️ Interactive Filters**
      -Month selection (January–December)
      -Mobile Model
      -Payment Method
      -Brand
      -Day Name
**🛠️ Tools & Technologies**
      -Microsoft Power BI
      -Data Modeling
      -DAX (Data Analysis Expressions)
      -Power Query (ETL)
**📂 Dataset Description**
The dataset includes the following fields:
Mobile Model,Brand,City,Sales Amount,Quantity,Transaction Count,Payment Methods,Customer Ratings,Date (Month & Day)
